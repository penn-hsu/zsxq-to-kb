# 知识星球文章抓取入库

一条链跑完：抓正文 → 校验完整 → 存成品 → 入知识库 → 重建索引。

## 前置

- 浏览器一律走 ego-browser 技能（编号 fs:md:ego-browser）。先跑 `ego-browser skill` 拿与已装版本匹配的指南，不要凭记忆写 API。
- 登录态：知识星球需要登录。没登录时请用户在内置浏览器窗口扫码一次，之后持久复用，不要替用户填密码。

## 步骤

### 1. 先摸清单，不先抓

打开专栏列表页，取出每篇的标题和 `articles.zsxq.com/id_xxx.html` 链接，列成清单给用户核对篇数。**篇数对不上就先停**，别抓一半发现漏了。

### 2. 逐篇抓正文

每篇开一个任务空间（taskSpace），`page.goto` 跳转后用 `page.evaluate` 取 `document.body.innerText`，抓完立刻 `task.finish()`，不堆积标签页。

### 3. 校验完整性（最容易翻车的一步）

三项都要过：

- 字数在合理区间（这类长文一般 5000 字以上）
- 结尾是完整句子，不是半截
- 小标题、导航块在不在

发现截断就滚到底重取。**截断的正文绝不入库**，宁可重抓。

### 4. 存成品

存到 `桌面\成品\知识星球-<系列名>\`：

- 正文按 `01-标题.md` 命名，开头写来源、作者、原文链接
- 配 `_index.json` 记录每篇的标题、链接、字数

### 5. 写入知识库

转成 `桌面\成品\我的知识库\notes\` 下的笔记，front matter 带 title、date、tags。

### 6. 重建索引并回读

跑 `python index.py --rebuild`，再按关键词和标签各查一次。条数对不上就回头查 front matter 格式。

## 踩过的坑

- **Windows 上脚本必须写成 UTF-8 的 `.mjs` 文件**，用 cmd 重定向运行：`ego-browser nodejs < 脚本路径`。PowerShell 5.1 会把 `-e` 里的双引号拆开、把中文读成乱码。
- 这台机器 `where node` 找不到 node，一律走 `ego-browser nodejs`，别想直接用 node 跑。
- 文件名带 `·`、`「」`、`—` 时读文件失败，先 `list_files` 拿真实文件名，别手敲路径。
- front matter 的标题别留半截引号或书名号，索引脚本按冒号切分会被污染。标题里的 `「」` 要成对闭合。
- 页面结构别凭记忆写选择器。先 `page.snapshot` 看清再动手，example.com 那次就是凭印象取 `h1` 结果拿到 null。
